# مُبدع الويب – تجربة رقمية عربية

واجهة ترويجية مبنية بـ **Next.js 14** تستعرض خدمات وكالة رقمية عربية، مع تجربة مستخدم جذابة باللغة العربية ودعم اتجاه الكتابة من اليمين إلى اليسار.

## المتطلبات

- Node.js 18 أو أحدث
- npm (يأتي مع Node.js)

## أوامر التشغيل

```bash
npm install   # تثبيت الاعتمادات
npm run dev   # تشغيل بيئة التطوير على http://localhost:3000
npm run lint  # فحص جودة الشفرة
npm run build # إنشاء النسخة الجاهزة للإطلاق
npm start     # تشغيل نسخة الإنتاج محليًا بعد build
```

## البنية العامة

```
app/           # صفحات Next.js (App Router)
  layout.tsx   # الهيكل العام والتعريب
  page.tsx     # الصفحة الرئيسية
  globals.css  # الأنماط العامة
```

## ملامح التجربة

- تصميم بصري غني يعتمد على التدرجات والطبقات الزجاجية
- محتوى عربي بالكامل مع دعم اتجاه RTL
- أقسام تفاعلية لعرض الخدمات والمنهجية
- نشر جاهز على Vercel مع تحسينات الأداء الافتراضية لـ Next.js

## النشر على Vercel

```bash
vercel deploy --prod --yes --token $VERCEL_TOKEN --name agentic-1100cd61
```

بعد النجاح يمكن التحقق من الموقع عبر:

```
https://agentic-1100cd61.vercel.app
```
